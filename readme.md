# Never Stop Blowing Up

A custom tabletop RPG system for Foundry Virtual Tabletop, inspired by Kids on Bikes and focused on explosive action and collaborative storytelling.

## Features

- Custom character sheets with stats, HP, and Boom Level
- Item support for explosives, gear, and upgrades
- Dice macros for fast gameplay
- Designed for Foundry VTT v12+

## Installation

1. Download or clone this repository.
2. Place the folder in your Foundry VTT `Data/systems` directory.
3. Enable "Never Stop Blowing Up" in your Foundry VTT game settings.

## Usage

- Create actors using the provided character sheet template.
- Add items to actors for gear and explosives.
- Use macros for dice rolls and actions.
